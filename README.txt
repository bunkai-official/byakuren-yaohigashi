管理と編集
・文章、料金、スケジュール、スタッフ: index.html の各 section 内
・配色、余白、文字サイズ: styles.css
・お知らせ詳細、行事予定、電話ボタン: script.js
・写真: assets/design-source.jpg の写真領域を CSS で表示しています。
・ヒーローの装飾文字は参照画像に含まれるアートワークです。
・実写真の原本がある場合は各 .photo を独立した img に差し替え可能です。

BUNKAI
既存のマジョルネと同じ静的 HTML/CSS/JavaScript 構成です。
サイト直下の index.html を公開する構成で、BUNKAI Gitへの移行用ソースです。

送信機能
マジョルネと同じ Netlify Forms 向けのフォーム属性を用意しています。
送信は data-submission-enabled="false" により無効です。
現時点では入力検証と内容確認のみ動作し、送信したとの表示は行いません。
実際の公開先でフォーム検出と受信先を設定・検証した後に有効化してください。
Netlify以外で公開する場合は、その公開先のフォーム受信APIに置き換えが必要です。
原稿にメールアドレス・電話番号がないため、電話番号は未設定です。
フォームには連絡先項目がないため、返信方法も公開前の確認事項です。
